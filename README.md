# 공마일 (0MILE)

> **0MILE - 업무의 출발점 / 공무원이 마음껏 일할 수 있는 플랫폼**


일정 · 문서 · PT · 엑셀 · 차트 · 레퍼런스 · API를 **한 화면의 탭**으로 모은 행정 업무용 웹 플랫폼입니다.
설치 없이 브라우저로 열어 바로 쓰고, 저장 위치를 바꾸면 사무실·집·출장지 어디서든 이어서 작업할 수 있습니다.

- 사이트: https://kwonyujin119.github.io/26vibecoding/

## 탭 구성

| 순서 | 탭 | 하는 일 |
|---|---|---|
| 0 | 홈 | 오늘의 결재판: 한 줄 명령, 오늘 일정·마감·할 일을 도장으로 처리, 시간대별 브리핑·마감 보고, 이어하기 |
| 1 | 부서장 일정 | 전 직원이 알아야 할 부서장 일정 공유 |
| 2 | 부서 스케줄러 | 부서 일정표·주요업무 관리 |
| 2.5 | 내 일정 | 개인 일정·할 일 (이 기기에만 저장, 부서 일정 겹쳐 보기) |
| 3 | 문서 | 한글(hwpx)을 대신하는 문서 작성 |
| 4 | PT | 발표 자료 만들기 |
| 5 | 엑셀 | 표 계산·서식 작업 |
| 6 | 차트 | 자료를 넣으면 여러 도표를 한 번에 보여 주고 고르기 |
| 7 | 레퍼런스 | 업무·디자인 참고 자료 모음 + 내 링크 |
| 8 | API 모음 | 업무에 쓰는 API를 클릭 한 번으로 접속 |
| 9 | 업데이트 기록 | 버전별 주요 변경 내용 |

넓은 화면에서는 왼쪽 메뉴(일정·작성·자료 묶음, 접으면 아이콘 줄)로, 휴대폰에서는 화면 아래 탭(홈·일정·작성·자료·전체)으로 이동합니다. 어느 화면에서든 **Ctrl+K**(맥은 ⌘+K)로 화면 이동·새로 만들기·최근 문서를 바로 찾고, **/** 로 한 줄 명령, Ctrl+K 의 **이어하기**로 마지막 작업을 이어서 엽니다. 브라우저 단축키(Ctrl+J, Ctrl+Shift+R 등)는 가로채지 않습니다. 주소 끝의 `#/docs` 처럼 탭 주소를 그대로 공유할 수도 있습니다.

## 홈: 오늘의 결재판 (2.0.0)

공무원의 하루는 **결재 서류 한 장**으로 정리됩니다. 홈은 위젯을 늘어놓는 대신 A4 공문 한 장, '오늘의 업무 · 2026. 11. 28.(토)'를 펼쳐 보여 줍니다.

- **1. 오늘 일정**(부서장·부서·내 일정을 시간 순으로, 지금 선), **2. 마감 업무**(기한 지남·오늘·이번 주), **3. 이어서 할 문서**, **4. 내 할 일**
- 항목 오른쪽 **도장**을 누르면 실제로 처리됩니다. 주요업무는 상태 '완료', 할 일은 완료, 일정은 '확인'(이 기기에만 기록). 다시 누르면 도장을 거둡니다(알림의 되돌리기도 됨).
- 오른쪽 위 **결재란**(기본 담당·팀장·과장)은 오늘 항목을 처리한 비율만큼 차례로 도장이 찍힙니다. 칸 이름은 ⚙ 설정 → 홈 결재판.
- **시간대**(설정의 출근·퇴근, 기본 09:00·18:00)
  - 아침 브리핑(출근 뒤 1시간까지): 오늘 건수와 첫 일정, 지난 근무일에 남은 할 일·내 일정을 '오늘로' 가져오기, 브리핑 글 복사
  - 근무 중: 지금·다음 일정과 남은 시간, 이어하기
  - 업무 마감 보고(퇴근 30분 전부터): 완료·미완료 목록, 미완료는 내일로, 메신저용 복사, **보고서로 저장**(문서 앱 보고서 서식으로 만들어 엶)
  - 머리 오른쪽 '보기: 아침·근무·마감'으로 언제든 다른 시간대를 볼 수 있습니다.
- **이어하기**: 문서의 스크롤·글자 위치, PT 슬라이드, 엑셀 시트·셀, 차트 파일을 기억해 홈의 '이어하기' 단추나 Ctrl+K 의 '이어하기'로 그 자리에서 다시 엽니다.

### 한 줄 명령

홈 맨 위 칸, 또는 어느 화면에서든 **/** · 명령 팔레트의 '한 줄로 만들기'. AI 없이 규칙으로 해석하므로 인터넷이 없어도 됩니다. 입력하는 동안 아래에 미리보기가 나오고, **Tab**(글 끝에서 →, 처음에서 ←)으로 넣을 곳을 바꾸며 **Enter**로 만듭니다. 만든 뒤 알림의 **되돌리기**는 방금 만든 기록을 지웁니다.

| 이렇게 적으면 | 이렇게 들어갑니다 |
|---|---|
| `내일 오후 3시 2층 회의실 김국장 업무보고` | 부서장 일정 · 김한결 국장 · 업무보고 · 11/29(일) 15:00–16:00 · 2층 회의실 |
| `국장님 모레 10시 도의회 출석` | 부서장 일정(직함으로 등록된 부서장 찾기) |
| `과장님께 내일 3시 결재 보고` | 내 일정 ('께'는 내가 가는 일정, Tab 으로 부서장 일정) |
| `다음 주 금요일까지 예산안 제출` | 주요업무 · 기한 12/4(금) |
| `나 금요일까지 연가 신청` | 내 할 일 · 기한 12/4(금) |
| `모레 10시 주간회의` | 내 일정 · 11/30(월) 10:00–11:00 (구분: 회의) |
| `12/3~12/5 세종 출장` | 내 일정 · 12/3(목)–12/5(토) 종일 |
| `부서 일정 12월 9일 전 직원 교육` | 부서 일정 · 전 직원 교육 · 12/9(수) 종일 (구분: 교육) |
| `3시부터 5시까지 민원 상담` | 내 일정 · 오늘 15:00–17:00 |
| `말일까지 실적 보고` | 주요업무 · 기한 11/30(월) |
| `보고서 새로` / `2027년 업무계획 작성` | 새 문서(보고서 / 계획(안) 서식)를 만들고 엶 |
| `PT 만들기 2027 비전` · `새 엑셀 출장비 정산` · `차트 만들기` | 새 PT · 새 통합문서 · 차트 만들기 |
| `우유 사기` (알아볼 말이 없을 때) | 내 할 일 · 오늘 |

- 날짜: 오늘·내일·모레·글피, 이번 주/다음 주 + 요일, 금요일, N일 뒤, 이틀 뒤, 2주 후, 이번 달·다음 달 N일, M월 N일, 12/3, 12.3, 2026.12.3, 말일, 주말, 2박 3일
- 시각: 오전·오후·아침·점심·저녁·밤 + N시(반, N분), 14:30, 3시~5시, 2~4시, 3시부터 5시까지, 2시간, 종일. 오전·오후가 없으면 1~6시는 오후로 봅니다.
- 개인 자료(내 일정·할 일)는 저장 위치를 클라우드·사무실 서버로 바꿔도 이 브라우저에만 저장됩니다.
- 해석기는 `js/nl.js` 한 파일이며 `P.nl.parse(글, 지금, { people })` 로 시험할 수 있습니다.

## 저장 위치 (왼쪽 메뉴 아래 단추로 한 번에 전환, 휴대폰은 오른쪽 위)

| 저장 위치 | 언제 쓰나 | 설정 |
|---|---|---|
| **이 브라우저** (기본) | 혼자, 한 PC에서 | 필요 없음 |
| **클라우드(Supabase)** | 어디서든 이어서, 부서원과 함께 | Supabase 무료 프로젝트 + `server/supabase.sql` 실행 + 작업공간 코드 |
| **사무실 서버** | 인터넷 없는 내부망에서 공유 | 사무실 PC에서 `python3 server/local_server.py 8787` |

- 전환할 때 "현재 데이터를 새 위치로 복사할까요?"를 물어봅니다. 연결에 실패하면 이전 위치를 그대로 씁니다.
- 한 사람이 연결을 마친 뒤 설정 창의 **연결 정보 복사**를 눌러 메신저로 보내면, 부서원은 **받은 연결 정보 넣기**에 붙여넣기만 하면 됩니다. (작업공간 코드가 들어 있으니 부서 안에서만 주고받으세요.)
- 부서장 일정·부서 스케줄러를 '이 브라우저' 저장으로 쓰면, 다른 사람에게는 보이지 않는다는 안내 띠가 위에 나옵니다.
- ⚙ 설정 → **데이터 백업**에서 전체 데이터를 JSON 파일로 내보내고 가져올 수 있습니다.
- 자세한 방법: [server/README.md](server/README.md)

## 주요 기능 요약

- **문서**: A4 쪽 편집, 서식 7종(빈 문서 포함), 항목 번호·표·그림, 공문서 점검, HWPX·DOCX·PDF(인쇄)·HTML·TXT 내보내기, HWPX·DOCX 가져오기
- **PT**: 슬라이드 편집, 서식·테마, 개요 글로 자동 만들기, 발표 모드, 품질 점검, PPTX·PDF·PNG 내보내기
- **엑셀**: 여러 시트, 수식, 서식·병합·틀 고정, 정렬·필터·조건부 서식·유효성, 템플릿 5종, XLSX·CSV 주고받기
- **차트**: 표를 붙여넣으면 어울리는 차트 여러 개를 한 번에 그려 비교, 골라서 저장·PNG
- **공통 파일 관리 (문서·PT·엑셀·차트)**: 탭을 누르면 목록(폴더) 화면이 먼저 나오고, 거기서 작업을 엽니다. 폴더 만들기·이름 바꾸기·삭제(안의 항목은 상위 폴더로), 끌어서 폴더로 옮기기, 검색(모든 폴더 포함)·정렬·목록/격자 보기, 여러 개 골라 이동·복제·삭제·내보내기(ZIP). 가져오기·내보내기 단추는 네 앱 모두 같은 자리(목록 머리 오른쪽, 편집기 윗줄 오른쪽)에 있고 **Ctrl+O**(가져오기), **Ctrl+Shift+E**(내보내기)로도 엽니다. 파일을 목록에 끌어다 놓아도 가져옵니다. (문서 본문에서 Ctrl+Shift+E는 가운데 정렬이 먼저입니다.)

## 알려진 한계

- 동시 편집은 없습니다(나중에 저장한 내용이 남음).
- 예전 HWP·DOC 파일은 한글·워드에서 HWPX·DOCX로 저장한 뒤 가져와야 합니다.
- 파일 변환은 글·표·기본 서식 위주이며, 복잡한 배치는 달라질 수 있습니다.
- 엑셀 피벗 테이블·매크로는 없습니다.
- Supabase 연결은 실제 Supabase 프로젝트에서 아직 시험하지 않았습니다(같은 SQL을 Postgres에서 확인).

자세한 변경 내용은 플랫폼의 **업데이트** 탭(`data/changelog.json`)에 있습니다.

## 다른 부서·기관에 보급하기

1. GitHub에서 이 저장소를 **Fork** 합니다.
2. 포크한 저장소의 **Settings → Pages** 에서 `main` 브랜치(루트)를 배포합니다.
3. 열린 사이트에서 ⚙ **설정 → 플랫폼 제목·부제·로고 글자**를 부서에 맞게 바꿉니다. (기관명은 코드에 들어 있지 않습니다.)
4. 부서 공유가 필요하면 Supabase 또는 사무실 서버를 연결하고, 작업공간 코드를 부서원에게만 알려 줍니다.

> 제목·테마 설정은 기기(브라우저)별로 저장됩니다. 부서 공통 제목을 처음부터 보이게 하려면 `js/core.js` 의 `DEFAULT_TITLE`, `DEFAULT_SUBTITLE` 값을 바꾸세요.

## 효과와 그림 자리 (1.4.0)

공통 효과는 `css/fx.css` · `js/fx.js` 두 파일에 있습니다. 앱 코드는 거의 건드리지 않고, 화면이 바뀔 때 정해진 선택자에 효과를 붙입니다.

| 종류 | 적용한 곳 |
|---|---|

### 그림 자리 (GPT 이미지 넣는 곳)

지금은 CSS로 그린 대체 그림(종이·도장)이 보입니다. 그림을 넣으려면:

1. 아래 이름으로 `assets/img/<이름>.webp` 파일을 넣습니다.

## 정보 효과 (1.6.0)

Magic UI · 21st.dev · React Bits 의 효과를 라이브러리 없이 `js/fx.js` · `css/fx.css` 에 다시 만들었습니다. 꾸밈이 아니라 알려 줄 내용이 있는 곳에만 씁니다.

| 효과 | 적용한 곳 | 알려 주는 것 |
|---|---|---|
| 흐르는 띠 (`P.fx.marquee`) | 레퍼런스 머리 띠 출처 사이트 (홈 '오늘 흐름'은 2.0.0에서 결재판 '1. 오늘 일정'으로 대신함) | 출처는 자료 수 순, 누르면 검색 |
| 테두리 빛 (`P.fx.beam`) | 부서장 일정·내 일정 일/주 보기와 홈 결재판의 진행 중 일정, 차트 추천 후보, 저장 위치 연결·복사 중 단추 | 지금(인주색), 추천·처리 중(남색) |
| 반짝 글자 (`P.fx.shimmer`) | 처리 중 단추(`P.ui.busy`), 불러오는 중 글자, 내보내기·복사 진행 알림, 저장 위치 바꾸는 중 | 기다리는 중. 제목에는 쓰지 않음 |
| 독 확대 (`P.fx.dock`) | 발표 모드 아래 단추 줄, 접힌 메뉴 아이콘 줄 | 커서가 닿을 단추 (마우스에서만, 최대 1.35배) |
| 글자 섞기 (`P.fx.scramble`) | 로고 0MILE (마우스·초점), 홈 큰 날짜 (그날 처음 · 자정), 명령 팔레트 결과 수 | 바뀐 값. 긴 글에는 쓰지 않음 |

- 효과 단계 **기본**: 띠·빛은 느리게, 독·글자 섞기는 끔. **끄기**와 기기의 '동작 줄이기': 띠는 가로로 넘기는 고정 줄, 빛은 1px 색 테두리, 반짝은 보통 글자, 독은 확대 없음, 섞기는 바로 최종 글자.
- 탭이 숨겨지거나 화면 밖이면 띠·빛·반짝을 멈춥니다. 띠의 이어 붙인 사본은 화면 읽기 프로그램과 키보드에서 빠집니다.
